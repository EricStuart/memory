## 使用约定

- 中文记录是快速导航和经验总结；涉及当前代码、线上数据或生产配置时，必须重新验证。
- 不记录生产密钥、私钥、完整环境文件和可直接使用的认证信息，只保留变量名、状态和安全操作原则。
- 本地验证、浏览器验证和远程部署验证分开描述，不能用局部成功替代端到端结论。
